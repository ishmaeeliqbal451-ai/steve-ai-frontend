Steve.AI Technical Overview

Project: Diana's Gym Assistant • Updates: Live • Status: Production Ready

1. System Vision

Steve.AI is an autonomous agent, not just a chatbot. It is architected to perform real business work for Diana's Gym.

  • Autonomous: Doesn't just reply; it books tours, emails leads, and escalates issues.
  • 3-Layer Architecture: Directives (Rules) → Execution (Python Tools) → Data (Google Sheets).
  • Hybrid Cloud: Runs on Modal (Serverless Python) with a lightweight GitHub Pages frontend.
